The work

Here's how I think about it.

Three areas where I focus, and one tool — AI — that's reshaping all of them. This is where I want to make the difference.

Architecture

Designing systems that absorb change. Choosing what to keep stable, what to keep flexible, and what to leave out entirely. Decisions that are still good in three years.

BPMN

Workshops, trainings, and hands-on enablement. Helping teams adopt BPMN seriously — not as wallpaper, but as a working language between business and engineering.

Engineering

Pairing on the tricky parts. Reviewing code that has to last. Mentoring engineers so the team is stronger when I leave than when I arrived.

AI

The tool I work with daily, and where I want to push hardest. AI lets teams produce code at unprecedented volume — which makes review the new bottleneck and quality the new risk.

I'm focused on the interfaces: guardrails, review patterns, and conventions that keep quality high without slowing teams down. AI used on purpose, not on autopilot.

Open source

I share what I build.

Honestly, I just like contributing. Sharing what works, getting honest feedback, solving the same problems together — we move further together than alone. Here are a few of my favourites.

bpmn-to-code

Kotlin★ 18⑂ 2

Type-safe constants from your BPMN model. Rename a task in the modeler — get a compiler error, not a 3am incident. Generate · Validate · Surface · Ship: a JVM toolkit that closes the drift between process diagrams and runtime.

View on GitHub →

distributed-horcruxes

Kotlin★ 6⑂ 1

The patterns nobody warns you about. Zeebe manages its own state next to your database — and the seams between them are where workflows go inconsistent. A working reference for the timing, idempotency, and outbox patterns that actually hold up in production.

View on GitHub →

slidev-addon-bpmn

TypeScript★ 4

BPMN diagrams that breathe in your slides. Drop a `.bpmn` file in `public/`, reference it with one component, and your diagram renders live via bpmn.io — interactive, sharp, and never a blurry screenshot again.

View on GitHub →

hogwarts

Shellmarketplace

Claude Code plugins, bundled. A single marketplace for the plugins I rely on daily: agento-patronum (shields secrets and sensitive files via PreToolUse hooks), felix-felicis (everyday automations), and revelio (per-repo log of failed tool calls).

View on GitHub →

engine-safari

Kotlin★ 1⑂ 1

Camunda 7 EoL is not optional. One newsletter-subscription process implemented across four embedded engines — Camunda 7, the Process-Engine-API abstraction, CIB-Seven, and Operaton — so migration teams can compare side by side and decide with eyes open.

View on GitHub →

easy-zeebe

Kotlin★ 2

A template you can clone, learn from, adapt. Hexagonal Zeebe + Spring Boot, type-safe BPMN constants, modeling conventions, ADRs, and AI-powered dev workflows — wrapped around a real process. Not a hello-world; a starting point that scales.
